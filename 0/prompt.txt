  ### Plugin marketplace format (supported)
  
  `~/.claude/plugins/known_marketplaces.json` lists sources such as `{"source":"github","repo":"typesafe-ai/skills"}` and `{"source":"git","url":...}`. To publish from a GitHub repo:
  
  ```
  <repo>/
    .claude-plugin/marketplace.json   {name, owner, plugins:[{name, source:"./", description}]}
    .claude-plugin/plugin.json        {name, version, description, skills:["./skills/x",...]}
    skills/<name>/SKILL.md (+ scripts/)
    commands/<name>.md                (auto-discovered, as in the slack plugin)
    hooks/ (optional, for the pr-receipts/SessionEnd hooks)
  ```
