On the scope question

Yes — materially better, and I'd revise my earlier note. My objection was that mime-db shipped 204 KB to derive ~40 entries that were fully determined at build time by a list already in the file. That's gone: the extension table is now indexed from all ~1000 mime-db types, and the rule reproduced is Roam's, not a curated one. No hand-written list reproduces 223 extensions, and the ticket's "emit Roam's embed syntax for each asset's media type" is what forces exhaustiveness. The dependency is now load-bearing.

The bundle cost is unchanged and still real: mimeDb is enumerated dynamically, so esbuild ships all of db.json into extension.js. If that matters, a build-time codegen step emitting the 223-entry table would keep the derivation and drop the runtime dependency — worth a follow-up ticket, not a blocker.
