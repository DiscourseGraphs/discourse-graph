> Why the preview toggle only appears while the result list has focus:
> 
> 1. In the query input, ←/→ stay caret movement, so the preview shortcut can only work while the result list has focus. Clicking a result gives it focus.

> Trade-off: a keyboard-only user can't open the preview, because only a click focuses the list. It's listed under Risk in the PR description.
