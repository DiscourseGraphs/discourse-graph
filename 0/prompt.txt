  ### e. Running a scene
  - **Scene loop** (RD:1353-1383). For each scene:
    1. Log `` `Scene ${index + 1}/${storyboard.scenes.length}: ${scene.name || ""}` `` with the `[recordDemo]` prefix.
    2. Push `{caption, toast, atMs: Date.now()}`. This mark is taken **before** `scene.open`.
    3. `scene.open` runs `page.goto(new URL(scene.open, page.url()), {waitUntil:"domcontentloaded"})`.
    4. `scene.wait_for` runs `waitForSelector(..., {timeout})`.
    5. Each `scene.do` action runs `runAction({ page, action, timeout, outDir, cursor: cursorMode })`.
    6. The narration hold runs (3f).
  
    There is no per-scene or per-action try/catch.
  - **Dispatch** (`runAction`, RD:708-1033) is an if/else chain on `"key" in action`, in this order: click, type, fill, press, hover, scroll, pause, wait_for, open, js, screenshot, drag, command_palette. Anything else throws `` `Unknown action: ${JSON.stringify(action)}` ``.
    - **click**: defaults are `button:"left"` and `count:1`. With `--cursor` it glides first. It then **always** calls `page.locator(sel).first().click({button, clickCount, position, timeout})`, per the comment "Keep Playwright's actionability checks after animating the cursor" (RD:721-744).
    - **type**: optional glide, then `locator.click`, then `page.type(into, text, {delay: delay_ms ?? 50, timeout})` (RD:745-753).
    - **fill**: `page.fill` (RD:754-755).
    - **press**: a string uses `keyboard.press`; `{selector,key}` uses `page.press`; `{key}` uses `keyboard.press` (RD:756-763).
    - **hover**: **always** glides, even without `--cursor`. If the element has no box it falls back to `locator.hover` (RD:764-772).
    - **scroll**: a number runs `window.scrollBy(0,n)`; `{to}` runs `scrollIntoViewIfNeeded`; `{y}` runs `scrollBy(0, y ?? 0)` (RD:773-789).
    - **pause**: in **seconds**, `waitForTimeout(action.pause * 1000)` (RD:790-791).
    - **wait_for**: `waitForSelector` (RD:792-793).

    const { stdout } = await execFileAsync("ffprobe", ["-v","error","-show_entries","format=duration","-of","default=noprint_wrappers=1:nokey=1", file]);
    const durationMs = Number(stdout.trim()) * 1000;
    if (!Number.isFinite(durationMs) || durationMs <= 0) { throw new Error(`Could not read video duration for ${file}`); }
    return durationMs; };
  
  export const getVideoTimeline = ({ videoDurationMs, demoStartMs, demoEndMs }) : { trimSeconds: number; trimOffsetMs: number } => {
    const demoDurationMs = demoEndMs - demoStartMs;
    if (demoDurationMs <= 0 || videoDurationMs < demoDurationMs) { throw new Error("The recording does not contain the complete demo timeline."); }
    // Persistent contexts begin recording restored tabs before launch resolves.
    // Anchor to the stopped video and measured demo duration, not a launch clock.
    const setupMs = videoDurationMs - demoDurationMs;
    const leadInMs = Math.min(1000, setupMs);
    return { trimSeconds: (setupMs - leadInMs) / 1000, trimOffsetMs: demoStartMs - leadInMs };
  };
