  ## 2b. Draft PR annotations (ready to post)
  
  1. **`publishNodesToGroups.ts:221`**: An Evidence node names its Source only in its title, and its source slot comes from that title (`sourceIdOfNode`). Roam keeps no back-reference to query, so this finds candidate pages by title substring. `sourceIdOfNode` then drops pages that contain the Source title without naming it as their source, such as a Claim that mentions it.
  
  2. **`:251`**: This repairs the drop in `omitMissingSource` from ENG-2293 (#1473). It only rewrites concepts this space already stored and never writes ResourceAccess. Publishing a Source grants no access to the nodes it repairs, and a node that was never published or synced stays out of the database.
  
  3. **`:283`**: Only rows stored without a reference get rewritten. A row whose reference already points at a different Source is left alone. That change reaches the database when the node itself is published again.
  
  4. **`:292`**: The restore sends the title and the reference, not `full`. Publishing a Source shouldn't push unpublished body edits of an Evidence node the user didn't select. (After F1, add: it keeps the stored `last_modified`, so the row doesn't claim a body version the database doesn't have.)
  
  5. **`:447`**: The old text told users to publish the referencing node again. Publishing the Source now restores the reference, so that instruction is gone. This covers sources of the Source type only (see line 525).
  
  6. **`:516`**: This runs after the main upsert, so the Source concept exists when `upsert_concepts` resolves the Evidence's `sourceDocument`. A failure goes to PostHog and doesn't fail the publish, because the Source itself did publish. Only Source-type nodes trigger it, so publishing other nodes adds no Roam query.
  
  7. **`:516` (parity breadcrumb)**: Obsidian repairs the same state during full sync (`findStaleSourceSlotNodeIds`, `apps/obsidian/src/utils/sourceSlot.ts:144`) by re-upserting the whole node. Roam's sync has no stale-slot check, so Roam repairs it when the Source is published.
  
  8. **`__tests__/publishNodesToGroups.test.ts:657`**: Without the restore call, this publishes twice with two `upsert_concepts` calls, and the Evidence row keeps no reference. The third call is the restore.

  - An Evidence already imported with the placeholder needs the per-page refresh (or the named follow-up ticket from F3).
  - Only Source-type sources are repaired.
  - Publishing a Source rewrites the stored title, core title and reference of other stored nodes the user didn't select.
